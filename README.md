# Inglés App

Experimento personal para aprender inglés desde cero (nivel A1), construido en secciones.

## Progreso del experimento

- [x] **Escritura (A1)** — completar oraciones, ordenar palabras y traducir frases.
- [ ] Verbos comunes (A1)
- [ ] Conversaciones básicas (A1)

## Cómo funciona

Es una aplicación web simple (HTML + CSS + JavaScript, sin dependencias ni instalación). Para usarla, abre `index.html` en el navegador.

El progreso de los ejercicios se guarda localmente en el navegador (localStorage), no se envía a ningún servidor.
